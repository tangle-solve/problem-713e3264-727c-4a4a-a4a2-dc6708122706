### ALGO-000170: Fixed-factor edit-distance approximation in n polylog n time
- **Subfield:** String algorithms and compression
- **Open:** Approximate edit distance within a fixed universal constant in \(O(n\,\mathrm{polylog}n)\) time.
- **Status:** Andoni–Nosatzki achieve constant-factor approximation in \(n^{1+\varepsilon}\) time for fixed \(\varepsilon\). This does not automatically give the stated running time with a fixed approximation factor.
- **Type:** theory
- **Why:** Would support fast alignment with robust worst-case guarantees.
- **Key works:** Andoni and Nosatzki, *Edit Distance in Near-Linear Time: It’s a Constant Factor*, arXiv:2005.07678, DOI: 10.1137/21M1392322.
- **Related:** Bioinformatics—sequence alignment; text processing—error-tolerant comparison.
